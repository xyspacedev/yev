# Decision Index 0.2.1: benchmark sources

Plan 5 (Stage 1) never trains on a reported benchmark. For the Decision Index this is enforced in two ways (plan 5, Ruling 1):

- **By name.** A public training source may not be any dataset listed below. `DECISION_INDEX_SOURCES` and `DECISION_INDEX_SHOWN_SOURCES` in `src/yev/filters/benchmarks.py` copy this table, and `tests/filters/test_benchmarks.py::test_public_long_sources_not_in_decision_index` checks the public slice against it.
- **By 8-gram fingerprint.** The test sets whose source dataset is already in our pool are fingerprinted (see the last section).

## Where the list comes from

The list comes from two places, both read on 2026-10-01 and 2026-10-02:

- the research report `jdi_workflowevals.md` (Plan 3 scratchpad), section "The 38 index benchmarks";
- the public reproduction kit `github.com/apolinario/decision-index` (MIT, pushed 2026-09-27), file `docs/suite.md`, which lists the pinned sources for editions 0.1 and 0.2.

Edition 0.2.1 rescores 0.2 with the same rows. 43 static benchmarks are in the suite. 38 count in the index; the other 6 (MMLU, ARC-Easy, ARC-Challenge, SimpleBench, RouterBench, SGD) are shown on the board but not counted.

The "Source ids" column holds the pinned source from `suite.md`: a GitHub `owner/repo`, a Hub dataset id, or a download host. Hub mirrors of the same data are added after it, marked (mirror). The mirror list is not exhaustive. Read the pinned revisions and files in `suite.md`.
